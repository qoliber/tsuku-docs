# About

## About Tsuku

**Tsuku** (つくる - *tsukuru* - "to create") was born from real-world e-commerce frustrations - specifically, the pain of working with XSLT for data transformations.

After years of wrestling with verbose XML stylesheets, complex template matching, and cryptic XPath expressions in production systems, it became clear there had to be a better way. A simpler way. A more maintainable way.

Tsuku emerged from these real needs:
- **Product catalog exports** - CSV/XML feeds for marketplaces and Google Shopping
- **API response formatting** - Clean JSON structures for integrations
- **Dynamic data transformation** - Converting database objects into various text formats
- **Configuration generation** - YAML/TOML files from structured data

What started as a solution for Magento projects has become a powerful, purpose-built library for any data transformation needs.
